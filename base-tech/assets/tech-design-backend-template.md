# 后端技术方案设计模板

> 按以下六章结构撰写后端技术方案。斜体为填写指引,正式方案中删除。

## 一、项目背景与目标

- **项目类型**:后台管理系统 / 微服务开发 / 其它
- **核心目标**:重构接口 / 完成某需求功能点 / 其它(一句话说明本次要达成什么)
- **边界限制**:覆盖需求文档的哪部分。*例:只关注教师端实现,学生端忽略*
- **需求清单**:需求地址(PRD / Wiki / 禅道链接)

## 二、总体架构设计

- **架构图**:包含系统交互、数据流向(可贴图或用文字 + Mermaid)
- **技术选型**:核心组件选型理由及对比
- **难点攻关**:预判的技术难点及解决方案

## 四、非功能性设计

- **稳定性与风险**:① 影响范围评估(*重点关注对旧功能的影响;升级公共 jar 包须明确影响范围*);② 大版本升级考虑新旧切换方案(开关 / 灰度)
- **性能评估**:容量预估、瓶颈分析及压测计划
- **安全设计**:数据脱敏、权限控制及防攻击策略
- **可观测性**:核心日志埋点、监控指标及告警阈值
